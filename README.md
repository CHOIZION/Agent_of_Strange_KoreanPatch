# Agent of Strange Arrival 한국어 패치 (Korean Translation Patch)

스팀(Steam) 게임 **Agent of Strange Arrival**의 비공식 한국어 패치 및 개발 도구 저장소입니다.

1. **패치 파일 다운로드**
   - 저장소 우측 **[Releases]** 탭에서 최신 버전의 `Agent_of_Strange_Arrival_Korean_Patch_v1.0.zip` 파일을 다운로드합니다.

2. **게임 설치 폴더 열기**
   - 스팀(Steam) 라이브러리에서 `Agent of Strange Arrival` 우클릭
   - **[관리]** ➔ **[로컬 파일 탐색]** 클릭

3. **파일 덮어쓰기**
   - 다운로드한 압축 파일 안의 `Agent of Strange Arrival_Data` 폴더를 게임 설치 폴더에 그대로 압축 해제합니다.
   - 대상 폴더에 동일한 파일이 있다는 경고창이 나타나면 **[덮어쓰기]**를 선택합니다.

4. **게임 실행**
   - 스팀에서 평소대로 게임을 실행하면 한국어가 정상 적용됩니다.
